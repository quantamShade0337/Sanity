# Changelog

All notable changes to Sanity are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses
[Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-11-20

### Summary
The first public release of Sanity: a menu bar utility for your Mac that shows how it's doing at a glance, adds a Dynamic Island to the notch, and gathers dozens of everyday tools in one place.

### Added
- A Dashboard that says in one line whether your Mac is fine, with processor, memory, battery and storage readings, recent activity and what is using your Mac right now.
- A Dynamic Island in the notch for volume, brightness, charging, AirPods connecting, Keep Awake, copies and saved captures, sized to fit what it shows.
- AirPods show their model and battery ring the moment they connect.
- Settings that explain each page in plain words, with search and a short setup guide.
- Sanity is available in 13 languages and follows the language you choose.
- A Credits page listing the projects Sanity is built on, with their licenses.

### Changed
- Feedback opens a GitHub issue on Sanity's repository.
- Sharing screenshots and recordings as web links is turned off until Sanity has its own link service.
