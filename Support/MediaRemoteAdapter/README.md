# MediaRemoteAdapter

Prebuilt copy of [MediaRemoteAdapter](https://github.com/ungive/mediaremote-adapter),
taken unchanged from Boring Notch's `mediaremote-adapter` folder. The notch reads
Now Playing information through it. A build step copies it into the app.
